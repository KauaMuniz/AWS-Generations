 📌 Sobre o projeto

Este repositório reúne laboratórios práticos, exercícios e implementações desenvolvidos durante minha formação em **Cloud Computing pelo programa AWS re/Start, da Generation Brasil**.

O projeto tem como propósito consolidar conhecimentos em computação em nuvem por meio da experimentação prática com serviços da Amazon Web Services (AWS), explorando desde o provisionamento de recursos computacionais até conceitos de redes, escalabilidade e distribuição de tráfego.

Mais do que registrar atividades, este repositório documenta minha evolução técnica, os desafios encontrados e a aplicação dos conceitos estudados ao longo da formação.

## 🎯 Objetivos

- Aplicar na prática os fundamentos de Cloud Computing.
- Compreender o provisionamento e o gerenciamento de recursos na AWS.
- Explorar arquiteturas com balanceamento de carga e escalabilidade.
- Desenvolver conhecimentos em redes, conectividade e infraestrutura.
- Utilizar ferramentas de linha de comando para interagir com serviços AWS.
- Aplicar Python em exercícios de programação e automação.
- Desenvolver boas práticas de documentação e versionamento com Git e GitHub.

## 🛠️ Tecnologias e serviços

| Tecnologia | Aplicação |
|---|---|
| **Amazon EC2** | Provisionamento e gerenciamento de instâncias computacionais. |
| **Amazon VPC** | Fundamentos de redes virtuais e conectividade na nuvem. |
| **Elastic Load Balancing (ELB)** | Distribuição de tráfego entre recursos computacionais. |
| **EC2 Auto Scaling** | Ajuste automático da capacidade computacional conforme a configuração definida. |
| **AWS CLI** | Interação com recursos e serviços AWS por linha de comando. |
| **Python** | Exercícios de lógica de programação e desenvolvimento de scripts. |
| **Git e GitHub** | Versionamento de código e documentação dos laboratórios. |
