# Desafio 2 — Separação da sequência de insulina

Exercício de Python para representar a sequência da insulina em variáveis
correspondentes às suas partes: sequência pré-proinsulina, peptídeo sinal,
cadeias B, C e A. Ao final, o script monta a sequência completa e calcula o
percentual de erro entre dois pesos moleculares.

## Arquivos

- `atribuir_variavel_sequencia.py`: definição das sequências, composição da insulina e cálculo do erro.

## Como executar

Na raiz do repositório:

```bash
python exercicios/Desafio2/atribuir_variavel_sequencia.py
```

## Conceitos praticados

- Atribuição e concatenação de strings;
- Organização de uma sequência em partes;
- Uso da função `abs`;
- Cálculo de percentual com operadores aritméticos.
