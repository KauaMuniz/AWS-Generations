# Desafio 1 — Recuperação da sequência proteica

Exercício de Python para ler a sequência de pré-proinsulina armazenada em
`preproinsulin-seq.txt`, remover espaços, quebras de linha e o identificador
`ORIGIN`, e exibir a sequência em uma única linha junto com a quantidade total
de caracteres.

## Arquivos

- `Recuperar_sequencia_proteica.py`: script responsável pela leitura, limpeza e contagem.
- `preproinsulin-seq.txt`: arquivo de entrada com a sequência original.

## Como executar

Na raiz do repositório:

```bash
python exercicios/Desafio1/Recuperar_sequencia_proteica.py
```

## Conceitos praticados

- Leitura de arquivos com `open`;
- Expressões regulares com `re`;
- Limpeza e concatenação de strings;
- Contagem de caracteres.
